Menyoo language files

Language files use the locale filename and editable JSON values:

  en-US.json
  fr-FR.json
  pl-PL.json

Copy a catalog, rename it to a locale tag, and edit the values. Select the locale in Settings > Language and use
Reload Language Files.

Keys are stable identifiers. Keep placeholders such as {count} and {fileName}
unchanged, although translators may move them within a sentence. Plural
messages use an object with a counter and forms:

  "items.message": {
    "plural": "count",
    "forms": {
      "one": "{count} item",
      "other": "{count} items"
    }
  }

Missing entries use English. GTA text labels (GXT) continue to follow the
game's language.
